## System-specific notes
----------
The data were generated by Pytorch 3.10 or higher versions. 


## How to use it?
----------
This toolbox contains a model (named modelmy.py), an optimized vmamba, as well as two files: main.py (for overall image processing) and mainpa.py (for patch processing). 

First, you need to install the official VMamba library. Then, in the VMamba.classification.models.vmamba directory, use this vmamba to insert or replace the original code. The main.py script provides an example experiment for using various datasets. After replacing the data path, you can directly run main.py and adjust different parameters to obtain the results. 
In addition, we provide a well-organized code framework that enables the splitting of samples in proportion or in fixed quantities. It also offers performance evaluation and visualization functions on the validation set and test set. You can directly run your own experiments by simply modifying the network structure. 

If you encounter any problems while using this code, please feel free to contact us at any time.
