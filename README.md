## How to use it?
----------
This toolbox integrates multiple directly callable cutting-edge contrastive models, including CSANet, SSTFormer, GLAformer, GTMSiam, SSMIF, and GASSM. Due to the complex file dependency relationships, SRGMGN and DBS3TAN have not been included in the unified management of this framework. In terms of experimental operations, the toolbox provides image-level processing script demo.py and patch block processing script demopatch.py. Among them, demopatch.py has integrated the call interfaces and parameter configurations of other mainstream methods, making it convenient for users to directly conduct comparative experiments by referring to the dataset settings in the original papers. 

For the specific architecture of the running environment, the GASSM method needs to be started by executing the demoGASSM file after configuring the standard Mamba environment. SSMIF relies on the VMamba environment. Users need to add the SSMIF.py file to the corresponding VMamba.classification.models.vmamba path in the official VMamba library, and then call it through demopatch. In addition, the GLDMambaP and GLDMamba proposed by us are also developed based on the VMamba environment and can be run in the demo and demopatch scripts. This toolbox provides a well-structured and highly modular code framework that supports flexible splitting of samples in proportion or in fixed quantities, and has a complete validation and testing evaluation system as well as visualization functions. Researchers only need to modify the network structure definition to efficiently conduct custom experiments within the existing framework. 

If you encounter any problems while using this code, please feel free to contact us at any time.
